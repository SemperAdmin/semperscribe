GenAI.mil base URL probe

Which base URL speaks CORS: api.genai.mil or genai.mil/stark/api? Ten seconds, no console needed.

Read this before reading the results. On the cors rows, RESOLVED is a PASS even when the status is 401, 403 or 404. A resolved promise proves the server sent Access-Control-Allow-Origin and the browser was willing to expose the response. Whether the path exists is a separate question and does not matter here. Only a REJECTED row means the CORS headers are missing.
Read the controls first. C1 must be OPAQUE and C2 must be REJECTED. If either misbehaves the run is VOID and every other row is meaningless.
Opened from disk this page sends Origin: null. A REJECTED cors row is conclusive. A RESOLVED cors row proves the host emits CORS headers permissive enough for a null origin, which is strong evidence and not final proof for the deployed origin. Re-run from the app origin to close that gap.
